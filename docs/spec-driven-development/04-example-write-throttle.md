# 04. 示例：写入限流策略（SDD 填写样例）

> 该示例展示如何把一个功能从规格写到可执行任务，供团队与 AI 共同参考。

## 1) Feature Spec 片段（示例）

- FS-1 目标：在高峰写入时保护存储节点稳定性，目标是将写入拒绝率控制在可配置阈值内，且 P95 查询延迟不劣化超过 5%。
- FS-3 功能：支持按租户维度令牌桶限流；支持动态开关。
- FS-5 兼容：关闭开关时行为与现网一致。
- FS-6 验收：
  - AT-1 高于阈值写入被限流并返回明确错误码。
  - AT-2 关闭开关后行为恢复基线。

## 2) Technical Design 片段（示例）

- TD-2 影响目录：`coordinator/`、`services/`、`lib/config`、`tests/`。
- TD-4 配置：
  - `write_throttle.enabled`（bool，默认 false）
  - `write_throttle.tokens_per_sec`（int）
- TD-6 回滚：配置开关置 `false` 即可回退。

## 3) Task Plan 片段（示例）

- T1：新增配置结构体与解析。
- T2：在写路径接入令牌桶校验。
- T3：补单测与集成测试。
- T4：补运维文档与告警模板。

## 4) AI 编码输入（示例）

```text
实现 T1/T2，严格遵循 FS-3.1、FS-5、TD-4、TD-6。
禁止修改未在 TD-2 出现的目录。
输出必须包含 AT-1/AT-2 对应测试命令。
```
